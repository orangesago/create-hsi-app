# create-hsi-app

Scaffold a new Vite or Next.js App Router SPA + React + TypeScript app from
the frontend template.

## Usage

### npm

```bash
npm create hsi-app@latest
```

### yarn

```bash
yarn create hsi-app
```

### pnpm

```bash
pnpm create hsi-app@latest
```

### bun

```bash
bun create hsi-app@latest
```

Full CLI usage, flags, and repo/install behavior:
[docs/CLI.md](https://github.com/orangesago/create-hsi-app/blob/main/docs/CLI.md)
